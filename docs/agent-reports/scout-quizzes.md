## 5. Webhook nodes + lead capture (release `a2b1e91` + `540de96`/`829d745` lineage)

- **The tier invariant** (`src/lib/quiz-webhook/tier.ts:9-70`), pure and unit-tested: (1) **an answer's own `setTier` outranks any lookup**; (2) **a returned tier steers routing ONLY if the quiz declares it** — anything else still reaches the lead as a value but may not select question variants (an undeclared tier would silently show the shared fallback and look correct); (3) **no answer never leaves a wrong tier** — provider down/slow/HTML degrades to the current (un)tier.
